# EZWebbing

A general-purpose, data-agnostic visual graph UI framework for Unity UGUI.
Connect nodes by dragging lines between pins — for detective boards, crafting
systems, skill trees, mind maps, and more.

- Requires Unity 2022.3 LTS or later (uGUI).
- The bundled **Mind Map** sample (import via Package Manager > Samples)
  additionally requires TextMeshPro (`com.unity.textmeshpro`). The core runtime does not.
